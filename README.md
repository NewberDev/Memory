### 🎮 게임 설명
**Memory**는 어두운 폐병원을 배경으로, 손전등으로 주변을 탐색하며 아이템과 단서를 수집하고 퍼즐을 해결해 탈출을 목표로 하는 3D 탑뷰 퍼즐/탈출 게임 데모입니다.

 제한된 시야 속 공간 탐색과 단서 조합을 통해 긴장감 있는 탈출 경험을 만드는 데 집중했습니다. 정적인 정보 표시를 넘어 드래그와 애니메이션을 활용해 UI 자체가 퍼즐로 기능하도록 구현했으며, 확장성을 고려한 컴포넌트 기반 상호작용 시스템을 설계했습니다. 또한 시야 제한 환경에서 필요한 정보를 전달하기 위해 조명, 외곽선, 포스트 프로세싱 기반의 시각 유도 연출을 적용했습니다.

## 🛠️ 핵심 구현 사항

### 1. 손전등 라이트 탐색 & 오브젝트 외곽선 감지 
- 손전등 조명을 활용해 어두운 공간을 탐색하며, 라이트 범위 내에 상호작용 오브젝트를 외곽선 및 이펙트로 시각적 유도합니다. 

### 2. UMG 인터랙티브 UI 퍼즐 
- 정적인 이미지를 넘어 마우스 클릭, 드래그, UMG 애니메이션을 결합한 인터랙티브 UI 퍼즐을 해결합니다. 퍼즐을 풀어 아이템을 획득하고, 탐색 영역을 확장합니다.

### 3. 시야 제한(Fog of War) & 포스트 프로세스 문 외곽선 감지
- 탑뷰 시점에서 플레이어가 위치하지 않은 외부 영역의 정보를 제한하고자 시야 제한(Fog of War)을 적용했습니다. 이로 인해 가려진 문과 통로의 위치를 플레이어에게 직관적으로 전달하고자, 문 근처 접근 시 포스트 프로세스를 통해 문의 외곽선이 강조되도록 연출했습니다.
